# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 1 is a behavior-preserving decomposition.** This contract documents the EXISTING UI as the locked baseline. Zero visual or interaction changes are permitted in this phase — the contract exists so Phases 2–3 (config-driven passcode, plat number, approver dropdown) have a stable reference.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-rolled Tailwind utility classes, no component library) |
| Preset | not applicable |

| Icon library | Lucide (CDN UMD global `lucide.icons`, rendered via `<i data-lucide>` + `lucide.createIcons()`) |

## Spacing Scale

Declared values (Tailwind default scale — all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding (`p-1`, `gap-1`) |
| sm | 8px | Compact element spacing (`p-2`, `gap-2`) |
| md | 12–16px | Default element spacing (`p-3`, `p-4`, `gap-3`, `gap-4`) |
| lg | 24px | Section padding (`p-6`, `mb-6`) |
| xl | 32px | Card padding (`p-8`) |
| 2xl | 40px | Large card padding (`p-10`) |
| 3xl | 64px | Page-level spacing (not used; max content width `max-w-6xl` header, `max-w-4xl` main) |

Exceptions: none — the app uses Tailwind's default spacing scale exclusively.

|------|------|--------|-------------|

| Label | 12px (`text-xs`) | 700 (`font-bold`) | normal |
| Micro-label | 10–11px (`text-[10px]`, `text-[11px]`) | 700–900 (`font-bold`/`font-black`) | normal |
| Heading | 20–30px (`text-xl` → `text-3xl`) | 900 (`font-black`) | normal |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Submit Log** (uppercase, `tracking-widest`); loading state: **Processing...** |
| Form heading | **Borrowing Request** |
| Empty state heading | **No borrowing requests yet** (no requests at all) / **No requests match your filters** (filtered empty) |
| Empty state body | Inbox icon (`Icon name="Inbox"` size 48, `text-white/40`) + the heading text above |
| Error state | **Error submitting** / **Error updating** / **Database not initialized** (notification toast, `type: 'error'`) |
| Success toast | **Request Logged Successfully** / **Details Copied!** / **Marked as {status}** / **Exported {N} requests** / **Passcode updated** |
| Destructive confirmation | REJECT: no confirmation dialog (immediate action, undoable via **UNDO REJECT**) |
| Modal titles | **Admin Access** (passcode) / **Mark as Returned** / **Request Details** |
| Modal cancel | **Cancel** (uppercase, `text-white/50`) |
| Form placeholders | **Requested By** / **Email** / **Phone** / **Equipment name (e.g. Tripod, Drone, Laptop)** / **Purpose of use...** / **Select vehicle** / **Select approver** |
| Form labels | **Expected Return Date** / **Borrow Time** / **Fuel Level** / **Equipment Condition** |
| Filter labels | **Search by name...** / **All Status** / **All Equipment** / **CLEAR** / **EXPORT ({N})** |
| Card micro-copy | **OVERDUE** (amber, uppercase) / **{N} days overdue** / **Due today** / **{N} days left** / **Borrowing for {N} days** / **Return by: {date}** / **Fuel: {level}** / **✓ Passed on {date}** / **✓ Approved by {name}** / **Returned: {condition}** / **· {N} requests** |
| Status pills | **{N} Pending** / **{N} Active** / **{N} Overdue** / **{N} Returned** / **{N} Rejected** |
| Clipboard fallback | `prompt('Copy this text:', details)` — last-resort tier on non-secure HTTP |
