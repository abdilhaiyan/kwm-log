User story (MVP): **As a** staff member **I want to** pick a plat number from a config-driven list or type a custom one, **and as a** manager **I want to** pick an approver from a config-driven list or type a custom one, **so that** adding new plates or approvers is a one-line constant edit and custom values are still recorded and displayed everywhere.

All four display surfaces (cards, detail modal, copied details, CSV export) read the same recorded fields and need zero changes (satisfied by construction).
